# French Comparatifs Practice

Interactive web page to practice French comparative structures:

- **plus... que** (superiority)
- **aussi... que / autant de... que / autant que** (equality)
- **moins... que / moins de...** (inferiority)
- Irregular forms: **meilleur**, **mieux**, **pire**

## Live demo

👉 **[Open the practice page](https://kranthib14.github.io/french-comparatifs-practice/)**

## How to use

1. Type your answers in the input fields
2. Click **Vérifier** (or press Enter) to check answers
3. Green = correct · Red = incorrect
4. Use **Révéler les réponses** to see the model answers
5. Score is tracked automatically (40 scored items)

## Features

- Complete interactive version of the original worksheet (10 exercises)
- Instant feedback with lenient handling of accents and apostrophes
- Sticky score counter
- Fully offline once loaded
- Mobile-friendly design

## Local usage

Just open `index.html` in any modern browser.
